# Launch readiness

This page tracks the work needed before OpenMausBot can run coding tasks reliably without an attended desktop session. See [the checklist](CHECKLIST.md), [current status](STATUS.md), and [technical investigations](DIGS-INDEX.md).

The launch requires repeatable scheduled coding, crash-safe publication, verified playbook availability, and an always-on coding host under launchd. Moving recurring tracker work into OpenMausBot is a later step, after the coding launch is verified.

A coding run does not authorize a merge, release, or package publication. The launchd host must run the coding service, not only report session status.
